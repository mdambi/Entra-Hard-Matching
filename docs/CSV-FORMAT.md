# CSV formats

All files: UTF-8, comma-delimited, one header row. Quote a field only if it contains a comma.
Real files contain identity data. They live in `data\`, `backups\` and `logs\`, which are git-ignored.
Fake examples are in `samples\`.

## stamp_list.csv (input for scripts 04, 05, 06)

Generated by `03-Build-StampList.ps1`, or maintained by hand.

| Column | Required | Format | Notes |
|---|---|---|---|
| `UPN` | yes | `user@domain` | Must equal the cloud UPN (case-insensitive). Must be unique. |
| `CloudId` | yes | GUID | Entra object ID (`Id` in `cloud_users.csv`). Must be unique. |
| `ImmutableId` | yes | 24-char Base64 ending `==` | Base64 of the 16-byte `ms-DS-ConsistencyGuid`, else `objectGUID`. Case-sensitive. Must be unique. |
| `SamAccountName` | no | text | Reference only. |
| `Wave` | no | text or number | Used by `-Wave` (scripts 05 and 06). Leave blank if you don't use waves. |
| `Notes` | no | text | Free text (department, branch...). |

```csv
UPN,CloudId,ImmutableId,SamAccountName,Wave,Notes
pilot.user@contoso.com,00000000-0000-4000-8000-000000009000,AAAAAAAAAECAAAAAAAAQAA==,pilot.user,0,Pilot - ICT staff
jane.doe@contoso.com,00000000-0000-4000-8000-000000010777,AAAAAAAAAECAAAAAABEhEQ==,jane.doe,1,Finance
```

### Validation (enforced on every run, the script stops on any failure)
- Required columns present, no blank values in them.
- UPN looks like an email, CloudId parses as a GUID, ImmutableId matches `^[A-Za-z0-9+/]{22}==$`.
- No duplicate UPN, CloudId or ImmutableId.

### Per-row safety checks (rows failing these are SKIPPED, never stamped)
- UPN domain is Managed (not Federated).
- CloudId exists and its cloud UPN equals the CSV UPN.
- Cloud user is not already synced and has no different ImmutableId.
- The ImmutableId is not already held by another cloud user.

## ad_users.csv (output of 01-Backup-AD.ps1)
Used by script 03. Required columns: `SamAccountName, UserPrincipalName, mail, ImmutableId`.
Also exported: `AnchorSource` (which attribute the value came from), `Enabled, DisplayName, Department, Title, DistinguishedName, ObjectGUID, ProxyAddresses, whenCreated, whenChanged, LastLogonDate, PasswordLastSet`.

## cloud_users.csv (output of 02-Backup-Entra.ps1)
Used by script 03. Required columns: `Id, UserPrincipalName, Mail, OnPremisesSyncEnabled, OnPremisesImmutableId`.
Also exported: `DisplayName, MailNickname, AccountEnabled, UserType, Department, JobTitle, CreatedDateTime, OnPremisesLastSyncDateTime, ProxyAddresses, LicenseSkuIds`.

## Exception files (output of 03-Build-StampList.ps1)

| File | Meaning | Action |
|---|---|---|
| `review_needed.csv` | Matched on UPN but unsafe (`Reason` column) | Fix the data, then rebuild |
| `ad_not_in_entra.csv` | AD user with no cloud account | Decide: new account, or map manually. Keep out of Connect scope until decided. |
| `entra_not_in_ad.csv` | Cloud user with no AD account | Usually shared mailboxes, service accounts, ex-staff. No action for stamping. |

## Run output (logs\)

| File | Contents |
|---|---|
| `<Script>_<DRYRUN\|APPLY>_<time>.log` | Timestamped run log |
| `<Script>_<mode>_<time>_results.csv` | One row per user: `Timestamp, UPN, CloudId, ImmutableId, Action, Detail` |
| `Test-SyncStatus_RUN_<time>_report.csv` | Per-user state from script 06 |

`Action` values: `WOULD STAMP`, `STAMPED`, `DONE` (already stamped), `SKIP` (safety check failed), `FAIL`, `WOULD CLEAR`, `CLEARED`.
